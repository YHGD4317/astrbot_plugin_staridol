# 娱乐圈模拟器

~~实际上是商业模拟器吧。~~ 依托AstrBot 插件进行的文字游戏，实现以养成为主的训练、工作、银行、经营、投资等核心系统。插件会持久化玩家的各项数据，并可以快捷导出/导入备份，即使更新或重装插件也不会丢档。 

## 主要特性

- **多角色注册**：玩家在群里可注册多位角色进行游玩，每个角色数据独立，也可以在玩家的安排下互相辅助。

- **双线养成系统**：作为集团总裁，玩家有口才、决策、财商、金钱属性，角色有口才、演技、唱功、舞蹈、情商、智商、武术、艺术、体力等属性。通过日常对艺人安排的训练、工作等养成和随机事件，可赚取或投资金钱，并让自己和角色们获得多方面的属性提升，更方便未来的经营布局。

  | 属性 |                             作用                             | 属性 |                        作用                        |
  | :--: | :----------------------------------------------------------: | :--: | :------------------------------------------------: |
  | 决策 |                    决策向事件中的判定依据                    | 舞蹈 |       MV、舞台剧、模特秀场等活动中的判定依据       |
  | 财商 |                    经营向事件中的判定依据                    | 情商 |        综艺、真人秀、访谈等活动中的判定依据        |
  | 金钱 |                     大部分行动所需的资源                     | 智商 |        综艺、真人秀、访谈等活动中的判定依据        |
  | 口才 | 玩家：口才向事件中的判定依据；角色：拍摄、演讲、访谈等活动中的判定依据 | 武术 | 拍摄电视剧/电影/MV、综艺、真人秀等活动中的判定依据 |
  | 演技 |          拍摄电视剧/电影/MV、演出等活动中的判定依据          | 艺术 | 拍摄电视剧/电影/MV、综艺、真人秀等活动中的判定依据 |
  | 唱功 |         发布歌曲、开演唱会、音乐剧等活动中的判定依据         | 体力 |      角色每次行动需要消耗的资源，可随时间恢复      |

- **项目投资**：玩家可投资电视剧、电影、歌曲、综艺、演讲、访谈、演唱会、真人秀等多种项目，并让名下角色参加以提高评分和利润，收获更多回馈。

- **经营系统**：玩家运营的集团可自定义名称，名下最初只有一家文娱公司，后续可投资影视公司、唱片公司、科技公司、药品公司等，逐步扩展自己的商业版图，赚取更多金钱。

- **银行经济**：日常可存/取款收取利息，在某些资金周转不开的时候可借贷。在存款数目上升后，可以提升信用等级，增加利率和贷款数额且降低利息率。

- **随机事件**：每日刷新需要玩家处理的个人事务，不定时刷新随机需要解决的事件，通过判定可获得随机奖励。

- **备份安全**：管理员可列出/创建/恢复备份，`重置游戏` 支持一键清档。

## 指令速查

| 分类 | 指令示例                                                     | 说明                                         |
| ---- | ------------------------------------------------------------ | -------------------------------------------- |
| 基础 | `信息/个人/系统面板` `xx开面板` `重开`                       | 查看玩家/角色面板、重置数据                  |
| 信息 | `查询面板@昵称` `查询xx `                                    | 查询其他玩家/角色/公司面板                   |
| 事件 | `今日行程` `检定xx`                                          | 查看/处理今日事务                            |
| 养成 | `x去参加xx` `x去练习口才/演技/…` `x去休息`                   | 让角色去工作/训练/休息                       |
| 项目 | `商业活动` `用x（数额）筹划/投资项目xx`  `xx项目开始`        | 项目相关指令                                 |
| 银行 | `存/取款xxxx` `领取利息` `银行账目` `升级信用`               | 银行与信用等级                               |
| 交易 | `打开商城` `（指定xx）购买x个xx `                            | 查看商城、购买道具/让角色代购道具            |
| 转账 | `转账xx给@昵称` `转移x的xx股份给@昵称` `打款给xx`            | 转账、转交股份、给名下公司/艺人打款          |
| 经营 | `集团面板/状态` `今日股市` `创建/投资xx公司x（数额）` `收取分红` | 查询集团/股市、创建或投资公司、收取分红      |
| 秀场 | `今日选秀` `聘用xx` `解聘xx` `转移xx到xx公司`                | 聘用/解雇/转移艺人（只能转移自己名下的艺人） |
| 管理 | `备份列表` `立即备份` `恢复备份<文件>` `@昵称重开` `重置游戏` | 备份/清档与维护                              |
| 概览 | `指令菜单`                                                   | 查看所有指令                                 |

## 面板参考

**玩家面板**：
xx董事长：玩家昵称（可自定义）

属性：决策x，财商y，口才z

金钱：以w结尾的数字

背包：放置道具，例如xx×1、xx×3

**集团/公司面板**：

xx集团/公司【隶属xx】

占股：玩家的集团及创建的公司占股为100%，如果是投资或合资的公司则按股价或商定占股

股价：xxx（xxx↑/↓）当日股价（对比昨日股价上涨或下跌）

（总）资产：在集团面板中为隶属该集团的所有公司加起来的总资产，在公司面板中仅为该公司拥有的资产

项目：集团或公司投资过的项目

公司：集团投资或玩家创建的公司

员工：集团内的艺人列表

**角色面板**：

顶流/一线/二线/三线/…：xx（100/100）这是体力条

属性：粉丝a，名声b，口碑c，口才d、演技e、唱功f、舞蹈g、情商h、智商i、武术j、艺术k

状态：参加xx中/练习xx中/休息中（预计xx时结束）
