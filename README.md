# 娱乐圈模拟器

> 依托 AstrBot 插件运行的娱乐向文字游戏，以**艺人养成**为核心，兼有今日事务、项目投资、商业活动、股市投资、银行信贷、商城道具与集团经营等玩法。插件会持久化玩家的各项数据，支持一键备份/恢复，更新或重装插件也不会丢档。

* **核心循环**：今日秀场招募艺人 → 花钱训练提升属性 → 投放到影视/音乐/综艺项目中提高评分 → 结算盈利 → 反哺养成
* **平台适配**：在 QQ 官方机器人上以 Markdown 卡片、可点击按钮、**自定义菜单**与**指令面板**呈现；其他平台自动降级为纯文本，玩法完全一致
* **文案规范**：插件内所有面向玩家的文本均不使用 emoji

## 核心玩法

### 一、集团注册

* 指令：`登记星海集团，决策50财商50口才50`
* 初始可自由分配 **150 点**属性到决策 / 财商 / 口才三项，**一个存档只能自由加点一次**；已加点后再次发送登记指令不会有任何回复。
* 初始资金 **1000w**，并自动获得一家「XX文娱公司」。
* `重开` 可清空自己的存档重新开始，之后可再次自由加点。

> 决策 / 财商 / 口才既是今日事务的判定属性，也直接决定自筹划项目的初始评分。

### 二、艺人养成（重点）

#### 1. 今日秀场

* 指令：`今日秀场`，每次随机抽取 **5 位**艺人，姓名与八项属性全部随机生成（1~100），默认**素人**等级，粉丝、人气、口碑均为 0。
* 每天可刷新 **3 次**（可用道具「秀场邀请函」恢复次数）。
* 再次发送 `今日秀场` 会**整批刷新**候选，上一批未签约的艺人将无法再聘用。
* 随机姓名若与历史上出现过的艺人重名，会重新抽取，保证不撞名。
* 卡片会为每位艺人附带一个「聘用」按钮，点击即填入签约指令。

#### 2. 训练与休息

指令：`林星野去训练舞蹈`（也可写 `练习`、`学习`；属性支持口才/演技/唱功/舞蹈/情商/智商/武术/艺术）

| 当前属性 | 单点花费 | 消耗体力 |  耗时  |
| :------: | :------: | :------: | :----: |
|   < 50   |   10w    |    5     | 1 小时 |
|  50~69   |   30w    |    5     | 1 小时 |
|  70~89   |   50w    |    5     | 1 小时 |
|   ≥ 90   |   100w   |    5     | 1 小时 |

* 训练结束后 **bot 主动推送**结果：`xx已完成唱功训练（唱功+1，目前唱功45）`。
* 有 10% 概率触发「灵感爆发」，一次提升 2 点。
* 指令：`林星野去休息` → 30 分钟后恢复 40 点体力。
* 体力每小时自然恢复 5 点；体力不足时无法训练或参加项目。

#### 3. 等级与工资

等级由低到高：**素人 → 五线 → 四线 → 三线 → 二线 → 一线 → 顶流**

| 等级 | 工资（参加项目时发放） | 晋升门槛（粉丝 / 人气 / 属性 / 达标项数） |
| :--: | :--------------------: | :--------------------------------------- |
| 素人 |          5w           | 1 000 / 20 / 单项 40 / 3 项               |
| 五线 |          20w          | 1 万 / 60 / 单项 55 / 4 项                |
| 四线 |          50w          | 10 万 / 150 / 单项 70 / 5 项              |
| 三线 |         120w          | 50 万 / 300 / 单项 80 / 6 项              |
| 二线 |         300w          | 200 万 / 600 / 单项 90 / 7 项             |
| 一线 |         800w          | 800 万 / 1200 / 单项 100 / 8 项           |
| 顶流 |         2000w         | 最高等级                                  |

满足条件后会自动晋升（也可发送 `晋升林星野` 手动确认），晋升会显著提高艺人的市场估值，从而提高集团总资产。

#### 4. 艺人状态与体力

* 艺人面板与集团面板会实时标注状态，例如：

```
顶流 林星野（95/100） 参加《项目名》中（预计 18:18 结束，剩余 1小时20分）
四线 苏清和（100/100） 练习唱功中（预计 19:05 结束，剩余 22分）
素人 白露（72/100） 待命中
```

* **同一艺人同一时间只能参加一个项目**，训练 / 休息 / 拍戏期间无法被安排其他行程。
* **参加项目期间，每小时消耗 8 点体力**；体力耗尽后拍摄仍会继续，但结束后需要安排休息。

### 三、今日事务

* 指令：`今日行程` → 发送带按钮的 Markdown 卡片。
* 点击按钮后，输入框会被自动填入 `检定口才` / `检定财商` / `检定决策`，玩家自行发送即可完成判定。
* **归属校验**：只有"自己发送过今日行程、拥有待检定事务"的玩家才能触发判定；其他人点击别人卡片里的按钮不会有任何回复。
* 判定完成后自动接续下一条事务卡片，直到当日事务全部完成。
* 指令 `事务进度` 可随时查看今日全部事务的处理情况。

每日事务数量：**基础 5 条**，集团总资产每突破一个档位 +1 条（档位不会因资产下滑而回退）：

```
7000w → 1 亿 → 3 亿 → 7 亿 → 10 亿 → 30 亿 → 70 亿 → 100 亿 → ...
```

档位越高，每条事务的金钱奖励也越高（每档 +35%）。

### 四、项目

#### 1. 自行筹划

指令：`用1000w筹划综艺（项目名）`

```
# 项目已立项
项目：《（项目名）》
类型：综艺
投资：1000w（已托管，结算后返还）
初始评分：0.7
预计时长：5 小时（随机 1~8 小时，玩家不可指定）
评分构成：基础 0.6 + 制作 0.1 + 艺人 0.0 = 0.7
[项目开始]
```

* **项目重名保护**：如果新项目与已有项目（含已结算的）重名，会自动追加序号，例如 `河中仙2`、`河中仙3`，形成系列项目。
* 指令：`项目开始`（或 `（项目名）项目开始`）→ 项目进入拍摄/录制。
* 指令：`林星野参加（项目名）` / `林星野、苏清和参加（项目名）` → 投放艺人。
  * 加入时**先发放该等级的薪资**，随后为项目增加评分。
  * **单个项目最多 6 位艺人**参与。
* 指令：`项目面板` / `取消项目（项目名）`。

#### 2. 评分构成

```
最终评分 = 基础分 + 制作加成 + Σ(每位参与艺人的加分)      （不设上限）
```

* **基础分** = `(项目主属性 + 财商) / 200`
  * 电视剧 / 电影 / 歌曲 / 模特秀 / 舞台剧 / 综艺 等使用**决策**
  * 演讲 / 访谈 / 真人秀 / 演唱会 / 音乐剧 / MV 等使用**口才**
* **制作加成** = `min(0.5, 投资额 / 10000)`，即投资 5000w 时 +0.5 分。
* **艺人加分** = `项目判定四项属性的平均值 / 100`
  * 例：口才 40、演技 50、武术 1、艺术 2 参加电视剧 → `(40+50+1+2)/4/100 = 0.2325 ≈ 0.2`
  * 属性越高加分越多，理论上没有上限。

各类型的判定属性：

| 类型 | 判定属性（取平均） | 玩家主属性 |
| :--- | :----------------- | :--------- |
| 电视剧 / 电影 | 演技 · 口才 · 武术 · 艺术 | 决策 |
| 歌曲 | 唱功 · 唱功 · 艺术 · 情商 | 决策 |
| 模特秀 | 舞蹈 · 艺术 · 情商 · 智商 | 决策 |
| 舞台剧 | 演技 · 唱功 · 舞蹈 · 口才 | 决策 |
| 综艺 / 真人秀 | 情商 · 智商 · 武术 · 艺术 | 决策 / 口才 |
| 演讲 / 访谈 | 口才 · 情商 · 智商 · 艺术 | 口才 |
| 演唱会 | 唱功 · 舞蹈 · 情商 · 艺术 | 口才 |
| 音乐剧 | 唱功 · 演技 · 舞蹈 · 艺术 | 口才 |
| MV | 舞蹈 · 唱功 · 艺术 · 演技 | 口才 |

#### 3. 结算与艺人成长

| 最终评分 | 结果 |
| :------: | :--- |
|  < 3.0   | 亏损**全部**投资额 |
| 3.0~4.9 | 亏损一半（返还 50%） |
|  ≥ 5.0   | `收益 = 投资 × (1 + (评分 - 5) × 10%)` |

* 例：投资 1000w，评分 6.5 → `1000 × 1.15 = 1150w`；评分 10 → 1500w；评分 20 → 2500w（评分不设上限，收益随评分线性增长）。
* 项目结束时 bot **主动推送**结算结果，并结算艺人的**粉丝 / 人气 / 口碑**成长（扑街项目会掉口碑）。
* 使用道具「聚光灯」可为本次结算的项目评分 +0.5。

### 五、商业活动

* 指令：`商业活动` — 每次发送都会**消耗一次机会并刷新** 5 个外部项目，每日 **3 次**（可用道具「招商手册」恢复次数）。
* 刷新后旧列表立即作废，**无法再投资之前出现的项目**。
* 每个项目明示：类型、时长、预期评分、所需投资额。指令 `投资1号项目` 直接投资，到期自动结算。
* 外部项目评分随机（1.5 ~ 7.5），**有坑也有漏**：评分低于 5 的项目注定亏损，需要自行判断。
* 外部项目同样遵循重名自动编号规则。

### 六、股市

股市由两类标的组成：**10 家独立公司**（全体玩家共享）与**玩家自己创建的公司**。

#### 1. 独立公司

* 每天随机开放 **3~5 家**公司进入「招标中」状态，只有招标中的公司可以投资；其余公司不带状态标注，表示暂不接受投资。
* 每家招标公司标注**每 1% 股份的单价**，例如 `单价 180w/1%`。
* **每日放出额度为 10%**：单次投资最多买入 10%，额度用完后该公司当日停止接受投资。
* 一家公司可以被多位玩家同时投资。
* 若某家公司 **100% 股份都被玩家持有**，在有人卖出之前它不会再开放投资。
* 未售出的股份会随每日行情波动（±12%）。

#### 2. 玩家公司

* 创建者可以自行决定是否开放投资、单价与放出份额：

```
开放投资星海影视公司，单价200w，放出30%
关闭投资星海影视公司
```

* 只有**创建者**有这项权限；以投资方式占股的玩家只能卖出自己的股份。
* 其他人买入时的资金**直接支付给公司创建者**。

#### 3. 买入与卖出

```
投资长河影业5%        -> 买入 5%，按单价扣款
卖出长河影业3%        -> 按当前单价的 85% 由市场即时回购
持股                  -> 查看自己的全部持仓与市值
```

* 单次买入上限 10%，不得超过当日额度与剩余可售份额。
* 卖出为市场即时回购，折价 15%，不会出现"卖不掉"的情况。

### 八、商城与道具

* 指令：`打开商城`，每日 0 点上架 8 种道具并**刷新价格**（基准价 ±25% 浮动）。
* 指令：`购买（道具名）` / `购买2个（道具名）`。
* **折扣机制**：每次购买前进行一次**口才检定**，通过后再进行**二次检定**决定折扣，最高 1 折、最低 9 折（只取整数折扣）。

| 类别 | 道具 | 基准价 | 作用 |
| :--- | :--- | -----: | :--- |
| 属性类（最贵） | 决策心得 / 财商指南 / 口才秘籍 | 320w | 玩家对应属性 +1 |
|  | 演技指导 / 唱功特训 / 舞蹈课程 / 台词脚本 / 情商课 / 思维训练 / 武术教习 / 艺术鉴赏 | 260~300w | 指定艺人对应属性 +1 |
| 恢复类（次贵） | 秀场邀请函 | 180w | 今日秀场次数 +1 |
|  | 招商手册 | 180w | 今日商业活动次数 +1 |
|  | 事务刷新卡 | 200w | 立即补发一条今日事务 |
|  | 能量饮料 / 营养餐 | 90w / 150w | 指定艺人恢复 30 / 60 点体力 |
| 临时类（较便宜） | 幸运符 | 70w | 30 分钟内检定属性 +15 |
|  | 聚光灯 | 90w | 2 小时内项目结算评分 +0.5 |
| 盲盒类（最便宜） | 神秘盲盒 | 40w | 随机开出上述道具或不定额金钱 |

* 指令：`使用幸运符` / `使用演技指导给林星野` / `使用能量饮料给苏清和`。
* 付款优先使用**现金**，现金不足时自动动用**存款**。

### 九、集团经营

* 指令：`创建影视公司`（可创建文娱/影视/唱片/经纪/科技/药品/传媒公司）。
* 公司每日自动产生收益并计入公司资产，指令 `收取分红` 可把利润提现。
* 公司资产与股价每日波动，可在 `集团面板` 中查看。
* 玩家公司可以开放股份给其他玩家投资（见 [股市](#六股市)）。

## 指令速查

括号中的内容需要替换成你自己的信息；示例之外的项目名、艺人名、集团名完全由你决定。

| 分类 | 指令示例 | 说明 |
| :--- | :--- | :--- |
| 基础 | `指令菜单` `信息` `集团面板` `重开` | 菜单 / 个人面板 / 集团面板 / 重置存档 |
| 注册 | `登记星海集团，决策50财商50口才50` | 创建集团并分配 150 点初始属性（仅一次） |

## 数值规则

### 属性检定

| 属性范围 | 骰点范围 | 大成功 | 成功 | 大失败 |
| :--- | :--- | :--- | :--- | :--- |
| < 100 | 1 ~ 100 | ≤ 5（双倍奖励 + 属性 +1） | ≤ 属性值 | ≥ 96（损失资金） |
| ≥ 100 | 1 ~ 属性 × 1.5 | ≤ 属性 × 0.1 | ≤ 属性值 | ≥ 属性 × 1.4 |

> 例：属性 120 时骰点为 1~180，12 点及以下为大成功，13~120 成功，168 及以上为大失败。

### 金钱单位

游戏内统一以 **w（万）** 为最小显示单位，`1 亿 = 10000w`。输入时支持 `1000`、`1000w`、`1000万`、`1.5亿` 等写法。

## 机器人菜单与指令面板

插件会自动把内置的快捷入口同步到 QQ 官方机器人（可在配置中关闭，管理员也可发送 `同步机器人菜单` 手动触发）：

* **自定义菜单**（仅 QQ 单聊生效）：共 8 个主菜单项，其中「更多」为二级菜单，包含登记集团、商业活动、今日股市、持股、指令菜单。点击后内容会填入聊天输入框。
* **指令面板**（群聊与单聊均生效）：包含 15 个常用指令入口，点击后把指令填入输入框。

> 菜单与面板中的登记菜单会向输入框填入 `登记` 两个字，交给玩家自行补全为 `登记（集团名），决策50财商50口才50` 后发送；若只发送 `登记` 而未填内容，机器人会提示正确格式。

## 消息投递与离线消息

QQ 官方机器人把消息分为两类，插件据此设计了投递策略：

| 类型 | 触发方式 | 配额 |
| :--- | :--- | :--- |
| 被动消息 | 回复用户刚刚发来的消息（携带 `msg_id`，5 分钟内有效） | 不计入主动消息配额 |
| 主动消息 | 机器人自己发起（训练完成、项目结算提醒等） | 有独立配额，超出后被平台拒绝 |

由于 `msg_id` 由 QQ 服务端签发并校验，**无法伪造或复用**（伪造的 `msg_id` 会被服务端直接拒绝，AstrBot 内部伪造事件也拿不到可用的 `msg_id`），所以主动提醒不可能完全绕开配额。

插件的做法是提供一个可靠的兜底通道：**结果先入离线队列，玩家下次发言时随回复一并送达**。这条通道走的是被动消息，不消耗任何主动消息配额。

投递方式由配置项 `notify_mode` 控制：

| 取值 | 行为 |
| :--- | :--- |
| `always_queue`（默认） | 完全不主动推送，结果统一进离线队列，玩家发任意游戏指令时提醒未读变动 |
| `push_first` | 先尝试主动推送；被拒绝时自动转入离线队列 |
| `push_only` | 只主动推送，失败即丢弃并记录日志 |

* 离线消息最多保留 20 条，超出时丢弃最旧的；每次补发最多 3 条，避免消息过长。
* 玩家可以随时发送 `未读消息` 主动取回队列中的全部内容。
* 玩家面板会显示未读条数。
* 跨天提示同样会搭在下一次回复里送出，不额外消耗推送配额。

## 插件配置

在 AstrBot WebUI 的插件配置页可调整（`_conf_schema.json`）：

| 配置项 | 默认值 | 说明 |
| :--- | :---: | :--- |
| `use_card` | true | 在 QQ 官方平台使用 Markdown 卡片 + 按钮 |
| `sync_bot_menu` | true | 启动时自动同步机器人自定义菜单与指令面板 |
| `notify_on_finish` | true | 训练/项目完成时推送结果 |
| `notify_mode` | always_queue | 结果投递方式：always_queue / push_first / push_only |
| `daily_quest_base` | 5 | 每日事务基础数量 |
| `show_refresh_times` | 3 | 每日秀场刷新次数 |
| `show_artist_count` | 5 | 每次秀场的候选人数 |
| `market_refresh_times` | 3 | 每日商业活动刷新次数 |
| `init_money` | 1000 | 初始资金（w） |
| `init_points` | 150 | 初始自由加点总数 |
| `tick_interval` | 20 | 后台扫描间隔（秒） |
| `max_artists` | 30 | 员工人数上限 |

> 当前默认即 `always_queue`：QQ 官方机器人通常没有主动消息权限（日志可见「主动消息失败, 无权限」），因此训练完成、项目结算等结果会进入离线队列，玩家发任意游戏指令时随回复提醒未读变动。

## 安装与维护

### 安装

1. 将插件目录放入 `AstrBot/data/plugins/astrbot_plugin_staridol`。
2. 在 WebUI 的「插件」页面点击刷新/重载。
3. 无需安装第三方依赖（仅使用标准库）。
4. 若机器人已在运行，可在群里发送 `同步机器人菜单` 手动同步菜单与指令面板。

### 数据与备份

* 存档位置：`AstrBot/data/plugin_data/astrbot_plugin_staridol/players.json`
* 备份目录：`AstrBot/data/plugin_data/astrbot_plugin_staridol/backups/`
* 管理员指令：`立即备份`、`备份列表`、`恢复备份（文件名）`、`重置游戏`
* 玩家指令：`重开`（仅清空自己的存档，同时释放其持有的股份）
* 数据每 5 秒（有变更时）异步落盘，插件卸载时强制保存。

### 平台说明

* **QQ 官方机器人**：卡片通过适配器持有的 `botpy` 客户端发送 `msg_type=2` 的 Markdown + `keyboard` 消息，按钮为「指令按钮」（点击后把指令填入输入框）。若发送失败会自动回退为普通消息。
* **主动推送**：训练完成、项目结算、项目体力透支、跨天提醒会先尝试主动推送到玩家最后一次互动的会话；被平台拒绝时自动转入离线队列，玩家下次发言随回复补发（详见 [消息投递与离线消息](#消息投递与离线消息)）。
* **其他平台**（如 aiocqhttp）：自动降级为纯文本，按钮以指令文字的形式给出。
